# Transonic Interceptor Wing & Fin Geometry Explorer

Interactive zero-dependency **Orthographic Isometric 3D Explorer** comparing flight-proven Counter-UAS (C-UAS) and transonic micro-missile aerodynamic configurations across the `~Mach 0.6–2.4` regime:

1. **01 Strake-Tail (`×`–`×`)** — Long-chord body strakes + pop-out tail CAS (*RTX Coyote Block 2 / 2C*)
2. **02 Forward Canard (`+` / `×`)** — Forward active clipped-delta canards + fixed swept aft tail (*LM MHTK, Rafael Tamir, Thales Martlet*)
3. **03 Mid-Slot + Curved `WATF`** — Mid-body slot guidance wings + curved Wrap-Around Tail Fins (*BAE APKWS II*)
4. **04 Clipped-Delta Dart** — Low-aspect-ratio supersonic clipped-delta wing + `40% MAC` balanced all-moving delta tail (*AV/BlueHalo Freedom Eagle-1, CAMM*)
5. **05 CG Switchblade (`×`–`×`)** — CG-centered switchblade wings + co-planar tail CAS (*Raytheon AGM-176B Griffin, Spike-LR2*)
6. **06 Reference Synthesis (`×` / `+`)** — `50°` swept CG switchblade `×`-wing + `45°`-interdigitated planar `+` rotary CAS

## Interactive Controls
- **Orbit & Zoom:** Drag anywhere on the viewport (or touch-drag on mobile) to orbit in true orthographic 3D; scroll to zoom.
- **View Presets:** Switch instantaneously between **Iso 3D**, **Axial Clock (Front)**, **Planform (Top)**, and **Profile (Side)**.
- **Vortex Wake & Bore Overlays:** Toggle **Wake** to compare co-planar vortex impingement vs. `45°`-interdigitated clean freestream lanes, and **Tube Bore** to inspect canister stowage clearance.
- **Live CAS Deflection:** Slide **CAS Deflection (`-20°` to `+20°`)** to visualize active control surface actuation about each topology's hinge line.
- **Deep Linking:** Click **Copy Link** to share a URL anchored to a specific configuration and view (`#config=06&view=iso`).
